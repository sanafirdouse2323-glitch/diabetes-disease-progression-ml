Key Research Insights

  • Sample-to-Parameter Ratio: Linear models (Lasso $\text{MAE } 42.70$) outperformed MLPs ($\text{MAE } 53.96$) because the 321-parameter network suffered an overparameterization bottleneck on 225 training observations ($P > N$).
  • Leakage-Free Validation: Preprocessing pipelines, calibration sets, and nested hyperparameter folds are strictly isolated to ensure reproducible generalization.
