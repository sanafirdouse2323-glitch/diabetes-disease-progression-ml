## 3. Split-conformal prediction intervals

The conformal procedure used absolute residual scores and the finite-sample rank
`k = ceil((n_cal + 1) * (1 - alpha))`. If this rank exceeds the number of calibration observations, the threshold is positive infinity, as required for the stated finite-sample construction.

| Model | Nominal marginal coverage | Observed test coverage | Mean interval width |
|---|---:|---:|---:|
| Mean Baseline | 90% | 93.3% | 240.433 |
| Linear Regression | 90% | 84.3% | 164.600 |
| Ridge | 90% | 89.9% | 181.196 |
| Lasso | 90% | 88.8% | 170.445 |
| Random Forest | 90% | 94.4% | 190.048 |
| PyTorch MLP (16, 8) | 90% | 89.9% | 219.819 |
| TensorFlow MLP (16, 8) | 90% | 94.4% | 269.726 |

The finite-sample conformal statement is a **marginal coverage guarantee over exchangeable calibration and future test observations**. It is not a guarantee that every individual model/test split will display at least 90% empirical coverage, nor a 90% probability statement about a particular person. The empirical values above are the observed coverage on one held-out set of 89 observations; Linear Regression and Lasso are below the 90% nominal level on this realized test partition. They are not hidden or rounded up.

## 4. Exploratory subgroup error analysis

The permutation p-values use 1,000 random relabellings with fixed group sizes and the plus-one Monte Carlo correction, `(1 + exceedances) / (B + 1)`. The values shown below are taken from the corrected end-to-end workflow artifact.

The code compares error across the two encoded values of the benchmark's standardized `sex` feature. These feature values are approximately -0.04464 and +0.05068; they are not literal group labels 0 and 1. The held-out groups contained 48 and 41 observations, respectively.

|---|---:|---:|

These are exploratory error-disparity summaries, not evidence that the models are fair or unbiased. The benchmark contains a small test cohort, and this analysis is not a comprehensive demographic fairness assessment. A non-significant permutation p-value does not prove the absence of disparity.

These quantities explain how the fitted models use the input features in this benchmark. They are associational, model-dependent attributions—not causal effects, validated clinical risk factors, or proof of biological mechanisms. Random Forest impurity importance can be biased by feature properties and correlations; it should not be interpreted as a causal ranking.

### Attribution method interpretation

* The Ridge coefficients and Random Forest mean-decrease-in-impurity values above summarize the fitted models. They describe associations in this benchmark, not causal effects.
* For a linear model, baseline-relative contributions are calculated as the fitted coefficient multiplied by the feature deviation from the model-fitting reference mean. Their sum matches the model's prediction difference from the reference profile, up to floating-point precision.
* For the Random Forest demo, local contributions use one-feature-at-a-time perturbations to the reference value. Because feature interactions and correlations can cause overlap, these contributions are not an additive decomposition and should not be read as SHAP values.
* The implementation does not include SHAP, neural input-gradient attribution, or causal inference.

## 6. Limitations and interpretation

1. **Small, preprocessed benchmark:** 442 observations and 10 preprocessed features are insufficient to establish clinical utility, transportability, or robust subgroup fairness.
2. **Single split:** The point metrics and empirical test coverage are from one seeded outer split. Repeated nested validation or external validation is needed to characterize variability.
3. **No clinical validation:** This work is an educational/research software demonstration, not a diagnostic or clinical decision-support system.
4. **Subgroup analysis is narrow:** Only the two encoded values of the standardized `sex` feature are compared. Age-group analyses and broader fairness evaluations are not included in this measured run.
5. **Interpretability scope:** The implemented methods are coefficients, Random Forest impurity importances, and local perturbation-style explanations. This run does not implement SHAP or causal inference.
6. **Neural comparison:** The neural models were trained for up to 100 epochs on 225 fit observations with a 57-observation early-stopping validation subset. Their test metrics should not be generalized beyond this benchmark and split.
